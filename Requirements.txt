# FreshFind — Complete Website Requirements

I want to build a complete **FreshFind** website using only **HTML, CSS, JavaScript, and JSON**. Do not introduce React, Tailwind, backend frameworks, databases, or other technologies unless I specifically ask for them.

The website should feel modern, polished, smooth, interactive, responsive, and visually attractive. The goal is to make it feel like a proper finished website rather than a collection of simple HTML pages.

## 1. Landing Page

Create a landing page that acts as an **introductory experience to FreshFind**, rather than looking like a normal webpage.

It should include:

* Beautiful and appropriate typography.
* High-quality fruit, vegetable, farming, and market imagery according to the purpose of FreshFind.
* A strong visual introduction to what FreshFind does.
* Smooth animations and transitions.
* An **"Explore FreshFind"** button.

When the user clicks **Explore FreshFind**, the transition into the actual website should feel smooth and intentional rather than simply looking like an instant page redirect.

The landing page should feel like an introduction/entry experience to the FreshFind platform.

# 4. Find A Market

Create a dedicated Find Market page.

Include a visually attractive hero section with an image that helps users understand that this page is for finding local markets.

Under the hero section, create a centered search/filter area.

The user should be able to:

* Search by market name.
* Filter by Area.
* Filter by Day.
* Filter by Time.
* Reset all filters.

The search and filters must work with the market data stored in JSON.

### Filter Dropdowns

The dropdown options should be generated from the JSON data where appropriate.

`10:00 AM`

Instead use user-friendly categories such as:

* Morning
* Afternoon
* Evening
* Night

Only matching market cards should remain visible after searching/filtering.

If no market matches the user's search/filter, display a clear:

**NO MARKET FOUND**

message.

Include a reset control to return to the complete market list.

### Market Cards

Display all markets from the JSON when no filters are active.

Each card should contain useful information such as:

* Market name
* Area
* Location
* Opening information
* Available produce
* Image
* Short description
* See Details button

The **See Details** button should be the way the user accesses the Market Details page.
